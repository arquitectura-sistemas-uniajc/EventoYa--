# Reconocimiento de Servicios Principales de AWS

## 1. EC2 (Amazon Elastic Compute Cloud)
Servicio de cómputo en la nube que permite crear e iniciar instancias de servidores virtuales. Se utilizará para desplegar los servicios backend de la aplicación EventoYa.

## 2. S3 (Amazon Simple Storage Service)
Servicio de almacenamiento de objetos diseñado para guardar y recuperar cualquier cantidad de datos de forma segura. Ideal para almacenar imágenes, activos estáticos y copias de seguridad del proyecto.

## 3. RDS (Amazon Relational Database Service)
Servicio administrado de bases de datos relacionales. Facilita la configuración, operación y escalabilidad de motores como PostgreSQL o MySQL para persistir los datos de EventoYa.

## 4. VPC (Amazon Virtual Private Cloud)
Red virtual lógicamente aislada dentro de AWS. Permite definir subredes, tablas de enrutamiento y grupos de seguridad para proteger los recursos del sistema.

## 5. AWS Billing and Cost Management
Herramienta de gestión financiera que permite supervisar los costos de AWS, analizar el uso del plan gratuito (*Free Tier*) y configurar alertas de presupuesto (*Budgets*).
